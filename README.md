# TutorSphere

TutorSphere is a tutor booking platform where users can explore tutors, book sessions, and manage their tutoring activities.

## Features

* 🔐 User Registration & Login
* 👨‍🏫 Browse Tutors
* ➕ Add Tutor
* 📚 My Tutors
* 📅 Booked Sessions
* 👤 User Profile
* 📊 Dashboard
* 🚪 Logout

## Technologies

* Next.js
* React
* Tailwind CSS
* HeroUI
* Express.js
* MongoDB
* Better Auth

## Run Locally

```bash
npm install
npm run dev
```

Backend server:

```bash
npm install
node index.js
```
